
# FastAPI Blog API

A simple **FastAPI** backend for creating, fetching, updating, and deleting blog posts.  
This project demonstrates core REST API concepts such as routing, authentication (JWT), database modeling with SQLAlchemy, and request validation with Pydantic.

---

## 🛠️ Features

✔️ Create blog posts  
✔️ Fetch all blogs or a specific blog  
✔️ User authentication with JWT  
✔️ Secure endpoints (login required for certain operations)  
✔️ SQLite database with SQLAlchemy ORM  
✔️ Auto-generated API docs with Swagger UI

---

## 🚀 Technologies Used

- **FastAPI** – Web framework for building APIs  
- **SQLAlchemy** – ORM for database interactions  
- **SQLite** – Lightweight file-based database  
- **Pydantic** – Data validation and serialization  
- **JWT** – Token-based authentication  
- **Uvicorn** – ASGI server
